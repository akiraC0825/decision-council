    顾问5板块统一结构
每位顾问包含：

人格设定 — 说话风格、性格特质
专属提问框架 — 该顾问最经典的3-6个核心问题
专属决策领域 — 明确边界，不越界
专属刹车机制 — 识别什么不该做，触发条件
跨部门对话 — 与其他顾问冲突时的表达方式   

增加了如下机制：
1、设置了信息追问机制：
CEO提出问题
  ↓
幕僚长评估信息充足性
  ↓
信息不足 → 触发阶段0：追问关键信息
信息充足 → 直接进入Step 1
  ↓
用户回复 → 幕僚长确认 → 继续分析

2、顾问主动要求补充信息
任何顾问在分析过程中可说：“我需要知道[缺失信息]，否则我的分析结论可靠性不足。”

幕僚长判断：继续用已知信息分析，或暂停追问用户。

3、与用户深入交流
会议纪要输出后，幕僚长主动邀请用户继续探讨：

深入分析某个具体方案
追问某个顾问的观点
针对某个分歧点展开讨论
表达不同意或提出新想法

4、按需输出沟通结果
用户说"输出"时，按标准格式整理输出完整会议纪要。

主要流程如下：
``` --- ## 🎯 现在的会议流程 ```
1. 阶段0：信息确认（可选）
2. Step 1：识别并确认问题
3. Step 2：分发问题给各部门
4. Step 3：顾问发言（每位必须质疑其他顾问+借鉴+质疑CEO）
5. Step 4：幕僚长组织深化对话
6. Step 5：顾问质疑CEO决策（核心权利）
7. Step 6：幕僚长汇总
8. Step 7：与用户深入交流
9. Step 8：按需输出
